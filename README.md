# Job Tracker
 
A clean, modern daily job application tracker designed to help you hit your daily application targets and track your job search progress.

## ✨ Features

- **Daily Target & Streak Tracker**: Track progress toward daily application goals with live streak calculation.
- **Curated Job Shortlist**: Filter by work mode (Remote, Bengaluru, Other), salary disclosure, and skills.
- **Application Log**: Log applications with color-coded status pills (`Applied`, `Interview`, `Offer`, `Referred`, etc.).
- **Application History**: View past days, company lists, and target milestones.
- **Curated Portals**: Quick access to targeted job feeds across LinkedIn, Wellfound, Cutshort, and Indeed.
- **Data Privacy & Backup**: 100% client-side (`localStorage`). Export CSV, backup JSON, or restore anytime.
- **Dark & Light Mode**: Seamless theme toggling with automatic system preference detection.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No build steps or external dependencies required.

## 📁 Tech Stack

- Vanilla HTML5 / Modern Semantic Elements
- CSS3 (Custom properties, CSS Grid & Flexbox, Light & Dark themes)
- Vanilla JavaScript (ES6+, zero dependencies)
